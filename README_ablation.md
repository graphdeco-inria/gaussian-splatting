# 가우시안 스플래팅 방법의 절제 연구(Ablation Study)

이 문서는 가우시안 스플래팅 기법에 대한 절제 연구(ablation study)를 위한 파일 구조와 실행 방법을 설명합니다.

## 개요

절제 연구는 제안된 기법의 각 구성 요소가 전체 시스템의 성능에 얼마나 기여하는지 분석하는 방법입니다. 이 연구에서는 다음과 같은 변형들을 평가합니다:

1. **기준선(Baseline)**: 증강 기법을 적용하지 않은 원래 방법
2. **전체 방법(Full Method)**: 모든 제안된 구성 요소(가시성 컬링, 패치 비교, 깊이 스무딩, 라플라시안 손실, 카메라 정렬)를 포함한 방법
3. **가시성 컬링 제외(No Visibility Culling)**: 가시성 인식 컬링을 제거한 방법
4. **패치 비교 제외(No Patch Compare)**: 패치 비교 기능을 제거한 방법
5. **깊이 스무딩 손실 제외(No Depth Smoothness)**: 깊이 스무딩 손실을 제거한 방법
6. **라플라시안 손실 제외(No Laplacian Loss)**: 라플라시안 손실을 제거한 방법
7. **무작위 카메라 순서(Random Camera Order)**: 카메라 순서를 사용(covisibility 기반)에서 무작위 방식으로 변경한 방법

## 파일 구조

절제 연구는 다음과 같은 파일 구조로 구성되어 있습니다:

```
auggs/gaussian-splatting/
├── ablation_study.sh         # 절제 연구를 위한 주 실행 스크립트
├── analyze_ablation.py       # 결과 분석 및 시각화 스크립트
└── README_ablation.md        # 이 문서

../experiments/ablation/      # 출력 결과가 저장될 디렉토리
├── 360/                      # MipNeRF360 데이터셋 결과
│   ├── <scene>_baseline/     # 각 장면별 기준선 결과
│   ├── <scene>_full/         # 전체 방법 결과
│   └── ...                   # 다른 변형의 결과
├── tandt/                    # TanksAndTemples 데이터셋 결과
│   ├── <scene>_baseline/
│   ├── <scene>_full/
│   └── ...
├── figures/                  # 결과 시각화 이미지
├── ablation_results_summary.csv  # 모든 결과의 요약 테이블
├── ablation_method_summary.csv   # 방법별 평균 성능 요약
└── ablation_report.md        # 결과 보고서
```

## 실행 방법

1. 전체 절제 연구 실행:

```bash
cd auggs/gaussian-splatting
./ablation_study.sh
```

이 스크립트는 각 장면에 대해 모든 방법 변형을 순차적으로 실행합니다. 완료하는 데 상당한 시간이 걸릴 수 있습니다.

2. 특정 장면에 대해서만 실행하려면 스크립트를 수정하세요:

```bash
# 스크립트 내의 장면 목록 변경
MIPNERF360_OUTDOOR="bicycle"  # 원하는 장면만 남김
```

3. 결과 분석 및 시각화:

```bash
python analyze_ablation.py
```

이 스크립트는 모든 실험 결과를 수집하고 분석하여 다양한 시각화 자료와 보고서를 생성합니다.

## 기대할 수 있는 결과

절제 연구가 완료되면 다음과 같은 결과를 얻을 수 있습니다:

1. **정량적 평가**: 각 변형에 대한 PSNR, SSIM, LPIPS 수치
2. **시각적 비교**: 각 방법별 렌더링 결과 이미지
3. **분석 보고서**: 각 구성 요소가 성능에 미치는 영향에 대한 분석
4. **시각화 자료**: 그래프, 히트맵, 레이더 차트 등 성능 비교 시각화

## 결과 해석

결과를 해석할 때 다음 사항에 주목하세요:

- **PSNR과 SSIM**: 값이 높을수록 원본 이미지와의 유사도가 높음을 의미
- **LPIPS**: 값이 낮을수록 원본 이미지와의 인지적 유사도가 높음을 의미
- **구성 요소의 영향**: 기준선과 전체 방법의 차이는 제안된 방법의 전체 기여도를 나타냄
- **개별 구성 요소의 효과**: 특정 구성 요소를 제거했을 때의 성능 변화는 해당 구성 요소의 중요성을 나타냄

## 참고 사항

- 실험은 MipNeRF360 데이터셋의 실내 및 실외 장면과 Tanks and Temples 데이터셋의 장면에 대해 실행됩니다.
- 모든 실험은 동일한 하드웨어 환경에서 실행되어야 공정한 비교가 가능합니다.
- 결과의 변동성을 고려하기 위해 여러 장면에 대한 평균 성능을 사용합니다.
