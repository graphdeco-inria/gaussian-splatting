
# Gaussian Splatting セットアップ手順

## Dockerを使用したセットアップ

### 1. 前提条件

#### 必要なソフトウェア
- Docker Engine (20.10.0以降)
- NVIDIA Docker runtime (nvidia-container-toolkit)
- NVIDIA GPU（CUDA Compute Capability 7.0以降）

#### NVIDIA Docker runtimeのインストール
```bash
# Ubuntu/Debian
curl -fsSL https://nvidia.github.io/libnvidia-container/gpgkey | sudo gpg --dearmor -o /usr/share/keyrings/nvidia-container-toolkit-keyring.gpg
curl -s -L https://nvidia.github.io/libnvidia-container/stable/deb/nvidia-container-toolkit.list | \
  sed 's#deb https://#deb [signed-by=/usr/share/keyrings/nvidia-container-toolkit-keyring.gpg] https://#g' | \
  sudo tee /etc/apt/sources.list.d/nvidia-container-toolkit.list

sudo apt-get update
sudo apt-get install -y nvidia-container-toolkit
sudo systemctl restart docker
```

### 2. GitHub Container Registry (GHCR) からのイメージ使用

#### イメージの取得
```bash
# 最新版の取得
docker pull ghcr.io/[YOUR_USERNAME]/gaussian-splatting:latest

# 特定のバージョンの取得
docker pull ghcr.io/[YOUR_USERNAME]/gaussian-splatting:v1.0.0
```

#### 学習の実行
```bash
# データディレクトリを準備
mkdir -p ./data ./output

# COLMAPデータセットでの学習
docker run --gpus all \
  -v $(pwd)/data:/app/data \
  -v $(pwd)/output:/app/output \
  ghcr.io/[YOUR_USERNAME]/gaussian-splatting:latest \
  conda run -n gaussian_splatting python train.py -s /app/data/your_dataset -m /app/output/model
```

#### インタラクティブな使用
```bash
# コンテナに入って作業
docker run -it --gpus all \
  -v $(pwd):/workspace \
  ghcr.io/[YOUR_USERNAME]/gaussian-splatting:latest \
  bash

# コンテナ内でconda環境をアクティベート
conda activate gaussian_splatting
```

### 3. ローカルでのビルド

#### Dockerイメージのビルド
```bash
# リポジトリのクローン（サブモジュール含む）
git clone --recursive https://github.com/graphdeco-inria/gaussian-splatting.git
cd gaussian-splatting

# イメージのビルド
docker build -t gaussian-splatting .
```

#### Docker Composeの使用
```bash
# 通常の実行環境
docker-compose up gaussian-splatting

# 開発環境（ソースコードをマウント）
docker-compose --profile dev up gaussian-splatting-dev
```

### 4. GitHub Actionsによる自動ビルド

#### リポジトリ設定
1. GitHubリポジトリの Settings > Actions > General
2. "Workflow permissions" で "Read and write permissions" を選択
3. "Allow GitHub Actions to create and approve pull requests" をチェック

#### 自動ビルドのトリガー
- `main`または`master`ブランチへのpush
- タグ（`v*`形式）の作成
- Pull Requestの作成

#### ビルドされるイメージタグ
- `ghcr.io/[USERNAME]/gaussian-splatting:main` - mainブランチ
- `ghcr.io/[USERNAME]/gaussian-splatting:v1.0.0` - バージョンタグ
- `ghcr.io/[USERNAME]/gaussian-splatting:sha-abc1234` - コミットハッシュ

### 5. 使用例

#### 基本的な学習
```bash
# シンプルな学習実行
docker run --gpus all \
  -v /path/to/your/data:/app/data \
  -v /path/to/output:/app/output \
  gaussian-splatting \
  conda run -n gaussian_splatting python train.py -s /app/data/scene

# 評価モードでの学習
docker run --gpus all \
  -v /path/to/your/data:/app/data \
  -v /path/to/output:/app/output \
  gaussian-splatting \
  conda run -n gaussian_splatting python train.py -s /app/data/scene -m /app/output/model --eval
```

#### レンダリング
```bash
# 学習済みモデルでのレンダリング
docker run --gpus all \
  -v /path/to/your/data:/app/data \
  -v /path/to/output:/app/output \
  gaussian-splatting \
  conda run -n gaussian_splatting python render.py -m /app/output/model
```

#### メトリクス計算
```bash
# 評価メトリクスの計算
docker run --gpus all \
  -v /path/to/output:/app/output \
  gaussian-splatting \
  conda run -n gaussian_splatting python metrics.py -m /app/output/model
```

### 6. トラブルシューティング

#### GPU認識の確認
```bash
# コンテナ内でGPUが認識されているか確認
docker run --gpus all nvidia/cuda:11.8-runtime-ubuntu22.04 nvidia-smi
```

#### メモリ不足への対処
```bash
# VRAM使用量を制限した学習
docker run --gpus all \
  -v /path/to/your/data:/app/data \
  -v /path/to/output:/app/output \
  gaussian-splatting \
  conda run -n gaussian_splatting python train.py \
    -s /app/data/scene \
    --data_device cpu \
    --densify_grad_threshold 0.001
```

#### ログの確認
```bash
# 詳細なログ出力
docker run --gpus all \
  -v /path/to/your/data:/app/data \
  -v /path/to/output:/app/output \
  gaussian-splatting \
  conda run -n gaussian_splatting python train.py -s /app/data/scene --debug
```
